# AI Doc & Task Extractor 📄

أداة ذكية لتحليل وتلخيص المستندات ومحاضر الاجتماعات واستخراج المهام والقرارات التنفيذية تلقائياً باستخدام تقنيات الذكاء الاصطناعي التوليدي.

---

### 🌟 المميزات الرئيسية
- **تلخيص سريع:** اختصار النصوص والتقارير الطويلة في نقاط أساسية واضحة.
- **استخراج المهام:** تحديد الـ Action Items وتحديد المسؤوليات تلقائياً.
- **واجهة تفاعلية:** مبنية بـ Streamlit لتوفير تجربة مستخدم سريعة وسلسة.

---

### 🛠️ التقنيات المستخدمة
- **Python**
- **Streamlit** (للواجهة)
- **Google Gemini API** (للتحليل اللغوي والذكاء الاصطناعي)
